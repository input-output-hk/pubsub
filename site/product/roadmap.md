# Roadmap

!!! info "Audience: All stakeholders"

We follow a **lean, phased approach** focused on rapid prototyping and iteration with stakeholder feedback.

---

## Timeline Overview

| Quarter | Phase | Key Deliverables |
|---------|-------|------------------|
| **Q3 2026** | Architecture | Architecture finalization, P2P prototype with modular DID integration |
| **Q4 2026** | SDK & Testnet | SDK draft (JS, Rust) for early integrators, SPO testnet deployment |
| **Q1 2027** | Mainnet | Production mainnet launch, wallet integration support (Lace, Eternl) |
| **Q2 2027** | Ecosystem | Developer documentation, 10+ dApp integrations, monitoring tools |

---

## Phase 1: Architecture & Prototyping (Q3 2026)

**Goal:** Validate architecture and build working prototypes.

- Finalize architecture design
- Build working P2P prototype with modular DID integration
- Engage wallet teams and DeFi protocols for feedback
- Produce SDK draft for early integrators

**Exit Criteria:** Architecture approved, working prototype demonstrated

---

## Phase 2: SDK & SPO Testnet (Q4 2026)

**Goal:** Developer tooling and network validation.

- Ship SDK (JavaScript, Rust) for early integrators
- Deploy SPO testnet with 50+ relay nodes
- Run integration pilots with 2-3 wallet teams
- Document API and integration patterns

**Exit Criteria:** SDK stable, testnet operational, pilot integrations complete

---

## Phase 3: Mainnet Launch (Q1 2027)

**Goal:** Production-ready decentralized network.

- Launch production mainnet
- Support wallet integrations (Lace, Eternl, Yoroi)
- Enable DeFi Intents message flow
- Establish monitoring and incident response

**Exit Criteria:** Mainnet live, 100+ SPO relay nodes, first wallet integration shipped

---

## Phase 4: Ecosystem Growth (Q2 2027)

**Goal:** Adoption and ecosystem development.

- Comprehensive developer documentation
- 10+ dApp integrations
- Monitoring and analytics tools
- Community governance framework RFC

**Exit Criteria:** 30+ dApp integrations, active developer community

---

## Future: Full Economy (2027+)

**Goal:** Sustainable economic model with community governance.

- Tokenomics RFC and community feedback
- Economic incentives for SPO relay operators
- DAO governance for protocol decisions
