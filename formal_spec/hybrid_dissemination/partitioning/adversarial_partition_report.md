# Adversarial Partitioning in H(N,2) RingCast: A Security Analysis

*Formal methods analysis | Tool: PRISM 4.10 probabilistic model checker*
*Architecture reference: Cardano Pub/Sub Framework Design and Architecture (D2, September 2024)*

---

## Summary

The dissemination layer of the Cardano Pub/Sub architecture uses a Harary graph H(N,2)
— a simple ring — augmented with random gossip links (r-links). We identify a targeted
**adversarial partitioning attack** in which an adversary controlling exactly **2 nodes**
can isolate any specific subscriber from the dissemination ring with probability
**e^{−RF} ≈ 13.5%** (for RF=2 r-links per node), regardless of the total number of
subscribers N.

The attack exploits three properties of the architecture that, in combination, create the
vulnerability:

1. Subscription is open — any node may subscribe to any topic.
2. The ring is ordered by node ID (public key), which is self-selected.
3. The architecture does not specify any mechanism to prevent ID grinding.

The result is independent of N: adding more subscribers does not reduce the adversary's
success probability. Only increasing RF (the number of r-links per node) reduces the floor,
at an exponential rate.

## Background

### H(N,2) Ring Topology

The architecture (Sec. 3.1.2) adopts a Harary graph of connectivity t=2 as the backbone of
the dissemination layer:

> *"In its most lightweight version, we employ a Harary graph of connectivity two, which
> essentially is a ring topology, and we also establish just one random link per node."*

A Harary graph H_{t,N} guarantees connectivity under up to **t−1 = 1** simultaneous node
or link failures. Each node maintains exactly **two ring links** — one to its predecessor
and one to its successor in the ring (Sec 3.3.3) — plus RF random r-links drawn from its
Cyclon gossip view.

### Link Directionality

The two link types have different directionality properties, both of which are significant
for the attack.

**D-links are effectively bidirectional.** Each node i maintains outgoing d-links to
*both* its predecessor (i−1)%N and its successor (i+1)%N. The dissemination ring is
therefore traversable in both directions — clockwise and counterclockwise — giving two
independent ring paths between any pair of nodes. This is consistent with H(N,2) being
the undirected cycle C_N: each undirected edge corresponds to two directed edges. It is
also confirmed empirically: our PRISM model gives P(partition | k=1) = 0, which would be
impossible if the ring were a one-way directed cycle (a single node removal would then
sever the unique path to the next node).

**R-links are unidirectional (directed).** Each node i has RF outgoing r-links pointing
to specific targets. Whether node j receives a message via an r-link depends entirely on
whether some other alive, reached node happens to have an r-link pointing *to* j. Node
j's own outgoing r-links are irrelevant for j *receiving* messages under push
dissemination.

**Why both properties matter.** D-link bidirectionality is what makes the minimum
adversarial budget k=2: one adversarial neighbor still leaves a d-link path via the
other. R-link directionality is what produces the e^{−RF} isolation floor: each of the
N−3 reached alive nodes independently misses j with probability (N−1−RF)/(N−1), and
isolation requires all of them to miss simultaneously. If r-links were bidirectional
(rl_i = j implying rl_j = i), node j would have RF guaranteed incoming r-links and
could never be isolated — the attack would not work.

### Ring Construction and Node IDs

The ring order is determined solely by node IDs (Sec.3.3.3):

> *"This process ultimately results in a ring structure where all same-topic nodes are
> ordered according to their IDs. The Vicinity selection function employed for this purpose
> relies on a single criterion, namely, node IDs."*

Node IDs are the nodes' public keys, self-generated by each participant.

### Open Subscription

The architecture explicitly does not restrict who may subscribe (Sec.2.1):

> *"Our design does not impose any constraints on the subscriber set of any topic...
> we define all topics as public, allowing any user to subscribe to any available topic."*

### Structural Guarantee vs. Adversarial Setting

The Harary graph guarantee (connectivity under t−1 failures) is a **crash-failure
guarantee**. It does not hold against a Byzantine adversary who can choose which nodes to
fail or how to behave. With t=2, two simultaneous targeted failures are sufficient to sever
all ring paths to one node, leaving it reachable only via random r-links.

## The Attack

### Goal

The adversary targets a specific subscriber j. The goal is that j does not receive a
disseminated event.

### Prerequisites

- The adversary knows j's public key (node ID). This is public information in a gossip
  overlay.
- The adversary can generate key pairs at will (no proof-of-work or ID commitment required
  by the architecture).
- The adversary can subscribe any node to any topic (open subscription).

### Attack Steps

**Step 1 — ID grinding.**
The adversary observes the current ring membership (learnable via gossip) and identifies
j's current predecessor ID `p` and successor ID `s`. The adversary generates key pairs
until finding:
- Key A₁ with ID in the interval (p, j) — becoming j's new predecessor.
- Key A₂ with ID in the interval (j, s) — becoming j's new successor.

With N honest subscribers, each target interval occupies roughly 1/N of the ID space.
The expected number of key generations needed is **O(N) per adversarial node** — trivially
cheap for any realistic N.

**Step 2 — Subscribe.**
Both adversarial nodes subscribe to the topic -- subscription is open.

**Step 3 — Wait for convergence.**
The Vicinity protocol converges and positions A₁ and A₂ as j's immediate ring neighbors,
displacing the previous honest predecessor and successor.

**Step 4 — Drop messages to j.**
When an event is disseminated, both A₁ and A₂ receive it and forward it along the ring
(to avoid detection) but **do not forward it to j**. Since both of j's ring links are
adversarial, all deterministic d-link paths to j are severed.

**Step 5 — Outcome.**
Node j receives the event only if some r-link from another (honest, reached) node happens
to point directly to j. This occurs with probability 1 − e^{−RF}. The adversary succeeds
(j misses the event) with probability **e^{−RF}**.

### Summary

| Parameter | Value |
|---|---|
| Adversarial nodes required | **2** |
| Key grinding cost | **O(N)** key generations |
| Authorisation required | None (open subscription) |
| P(j misses event), RF=1 | **≈ 36.8%** |
| P(j misses event), RF=2 | **≈ 13.5%** |
| Dependence on N | **None** (asymptotically) |

## Formal Analysis

### Model

We modelled the graph connectivity question using PRISM 4.10, a probabilistic model
checker. The model (`ringcast_n6_adversarial.prism`, `ringcast_n6_adversarial_rf2.prism`)
captures:

- N=6 nodes, node 0 = source, H(N,2) ring (2 d-links per node).
- Adversary pre-selects a set S of k nodes to remove before r-links are sampled.
- R-links sampled uniformly at random (RF=1: one r-link per node; RF=2: ordered pair
  without replacement).
- Directed reachability from source to all live nodes computed by BFS.
- Property: P(some live node is unreachable from source).

The model is a DTMC, run separately for each adversary choice S (one PRISM execution per
choice). The maximum over all C(N−1, k) choices gives the adversary's best strategy.
All results are **exact** (not statistical).

### Results: Optimal Adversary Strategy

The adversary's optimal strategy for k=2 is always the **alternating cut**: kill both
ring neighbors of a single target node j, severing all d-link paths to j. The results
below give the maximum partition probability over all adversary choices.

**RF=1 (one r-link per node)**

| k (kills) | Adversary's best S | P(partition) |
|---|---|---|
| 0 | — | 0.000 |
| 1 | any | **0.000** |
| 2 | {1,3}, {2,4}, or {3,5} | **0.512** |
| 3 | {1,3,5} | **0.920** |
| 4 | {1,2,3,5} etc. | **0.800** |

**RF=2 (two r-links per node, as in the asymmetric dissemination model)**

| k (kills) | Adversary's best S | P(partition) |
|---|---|---|
| 0 | — | 0.000 |
| 1 | any | **0.000** |
| 2 | {1,3}, {2,4}, or {3,5} | **0.216** |
| 3 | {1,3,5} | **0.660** |
| 4 | {1,2,3,5} etc. | **0.600** |

### The e^{−RF} Bound

For the optimal k=2 strategy (kill both neighbors of target j), there are N−3 alive
reachable nodes each holding RF r-links. The probability that all r-links miss j is:

$$P(\text{j isolated}) = \left(\frac{N-1-\text{RF}}{N-1}\right)^{N-3} \xrightarrow{N \to \infty} e^{-\text{RF}}$$

This limit is **independent of N**. The convergence is fast:

| N | RF=1 | RF=2 | RF=3 |
|---|---|---|---|
| 6 | 0.512 | 0.216 | 0.064 |
| 10 | 0.439 | 0.172 | 0.059 |
| 20 | 0.399 | 0.151 | 0.054 |
| 50 | 0.379 | 0.141 | 0.051 |
| 100 | 0.374 | 0.138 | 0.051 |
| ∞ | **0.368** | **0.135** | **0.050** |

For RF=2 (the model studied in `hybrid_diss.pdf`) the floor is **≈ 13.5%** regardless
of how large the ring grows.


### k=1 Is Safe

Removing any single node never disconnects H(N,2): the ring has two independent directed
paths between any pair of nodes, so one removal always leaves a path. This is the
structural 2-connectivity guarantee of the Harary graph. The adversary strictly requires
k=2 to create any partitioning risk.

## Severity Assessment

The attack is significant for the following reasons:

**Low adversarial cost.** Only 2 controlled identities are needed. Key grinding costs
O(N) hash evaluations per node — negligible for any realistic ring size. No stake,
no proof-of-work, no existing reputation is required.

**Targeted.** The adversary can choose any specific subscriber j to isolate. This
enables selective censorship: a specific node can be denied all events on a topic while
all other nodes receive them normally.

**N-independent floor.** Scaling up the ring does not help. The e^{−RF} floor is
a fundamental property of the H(N,2) + random r-link structure, not a finite-size
artefact.

**Undetected operation.** Adversarial nodes A₁ and A₂ forward messages correctly to
all nodes except j. From the perspective of other nodes, A₁ and A₂ behave as honest
participants. j cannot distinguish "no message published" from "message suppressed."

**Not addressed by SecureCyclon.** SecureCyclon (Sec.3.3.1) prevents nodes from
manipulating their gossip link set beyond what the protocol allows. It does not restrict
which IDs nodes may register or which topics they may subscribe to. The attack does not
require any gossip manipulation — only legitimate subscription and selective message
dropping.

---

## Conclusions

1. **The H(N,2) ring topology, combined with open subscription and self-selected node IDs,
   admits a targeted adversarial partitioning attack requiring only 2 controlled nodes.**
   The adversary grinds key pairs to become the immediate ring neighbors of a target, then
   silently drops messages destined for that target.

2. **The attack's success probability is e^{−RF}, a floor that does not decrease with N.**
   For RF=2: ≈ 13.5%. For RF=1: ≈ 36.8%. Scaling the ring provides no protection.

3. **The attack is undetected and targeted.** Adversarial nodes behave honestly toward
   all other subscribers. Only the specific target is affected.

4. **The architecture document does not address this attack vector.** SecureCyclon
   prevents gossip manipulation but not ID grinding or selective message dropping.
