## Core KPIs

| Core Cardano 2030 KPIs | Alignment | KPI Alignment Narrative |
|------------------------|-----------|-------------------------|
| **TVL (Total Value Locked)** | Yes, enable | Enables Babel Fees via DeFi Intents, reducing friction for users to lock value in DeFi protocols. Lower barriers → more TVL. |
| **Monthly Transactions** | Yes, directly | Every intent fulfilled becomes 1+ transactions. DeFi agents generate high transaction volume. PubSub-enabled use cases (governance voting, dApp interactions) create new transaction sources. |
| **Monthly Active Users (MAU)** | Yes, enable | Wallet-native notifications improve user engagement. ADA-free intents lower barrier for new users. Users who churned due to missing alerts can re-engage. |

## Strategic Value Beyond Metrics

### Competitive Positioning

| Ecosystem | Intent/Messaging Infrastructure |
|-----------|--------------------------------|
| **Ethereum** | ERC-4337 account abstraction + intent protocols (CoW Protocol, 1inch Fusion) |
| **Solana** | Jito for MEV/intent infrastructure |
| **Cardano** | ❌ No native messaging layer (PubSub fills this gap) |

### Ecosystem Revenue Enablement

PubSub enables new revenue streams that don't exist today:

- **Premium notification services** — Protocols charging for priority alerts
- **Intent marketplaces** — Agents paying for order flow access
- **Subscription-based dApps** — Real-time data feeds and alerts
- **Cross-protocol coordination** — Multi-dApp workflow fees
