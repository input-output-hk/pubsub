# Vertical 3: Commerce & Services

**The In-Wallet "dApplet" Storefront**

This vertical focuses on realizing a "Super Wallet" strategy by enabling a vibrant in-wallet marketplace of lightweight applications ("dApplets") for commerce and entertainment.

## Use Cases

### In-Wallet NFT Marketplace

A dApplet that allows users to securely browse, bid on, and purchase NFTs via actionable Cardano PubSub messages without ever leaving their wallet.

**Core Benefit:** Streamlines the user experience and reduces security risks from connecting to third-party sites, capturing more economic activity.

---

### Interactive E-commerce

Brands and businesses can deploy dApplets for direct-to-consumer sales, turning promotional offers into interactive mini-applications for browsing and purchasing.

**Core Benefit:** Creates new, direct-to-consumer revenue models on Cardano and lowers the barrier for Web2 businesses to enter the ecosystem.

---

### Gamified Onboarding

Simple, viral games built as dApplets that introduce new users to core crypto concepts (earning tokens, using a wallet) in a fun, low-stakes way.

**Core Benefit:** Solves the user acquisition problem by creating a powerful, viral onboarding funnel.
