# Vertical 5: Ecosystem Expansion

**Cross-Chain Growth**

This vertical directly addresses the challenge of user base expansion by using Cardano PubSub as a communication and interaction bridge to attract users and liquidity from other ecosystems. *A key requirement identified by Minswap.*

## Use Cases

### Actionable Cross-Chain Governance

A Cardano-based DAO sends proposal notifications to all its token holders, even those on EVM chains. The message includes embedded "Vote Yes/No" buttons, allowing a user to sign with their native wallet (e.g., MetaMask) to vote on a Cardano proposal.

**Core Benefit:** Transforms cross-chain governance from a complex process into a seamless, one-click experience, massively lowering the barrier to participation for external token holders.

---

### One-Click "Bridge and Stake"

A Cardano DeFi protocol sends a targeted, interactive message to users on other chains advertising a superior yield. A "Stake Now" button initiates a pre-configured flow that bridges assets and stakes them in one user-approved action.

**Core Benefit:** Creates a powerful, low-friction liquidity acquisition funnel, directly converting awareness on other chains into Total Value Locked (TVL) on Cardano. *Directly addresses Minswap's primary pain point.*

---

### Portable Cross-Chain Reputation

An identity protocol on Cardano PubSub aggregates a user's interactions across multiple chains (e.g., governance on Cardano, lending on Aave) to build a holistic, portable on-chain reputation score using their Hyperledger Identus DID.

**Core Benefit:** Creates a valuable, portable digital identity asset for users and a powerful trust layer for the entire Web3 ecosystem, anchored by Cardano.
